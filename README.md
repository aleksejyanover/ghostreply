# GhostReply 📝

Приложение, **которое пишет сообщения в мессенджере вместо тебя**.

Ты скидываешь ему историю чата — оно разбирает **твой стиль** (длина сообщений,
эмодзи, капс, восклицания, фирменные слова, как здоровякаешься) и отвечает
собеседнику так, как отвечал бы ты сам.

## Что умеет

- **Реальные мессенджеры** — вставляешь ссылку + токен, и бот отвечает
  **в самом VK или Telegram**, а не внутри приложения.
- **Стиль по истории** — профиль строится из твоих сообщений, а не из шаблонов.
- **Ответ по контексту** — смотрит последние N сообщений чата и отвечает на последнее.
- **Реалистичность** — «печатает…» и пауза 1–2.5 сек перед отправкой,
  как у живого человека.
- **Живая лента событий** — видно, что пришло и что бот ответил.
- **Веб-интерфейс** — чаты, стиль, настройки, подключения в одном окне.
- **HTTP API** — подключается и к своему мессенджеру.
- **Два режима** — `auto` (отправляет сразу) и `draft` (черновик, решаешь сам).
- **Фолбэк без сети** — если LLM недоступна, отвечает локально по намерениям.
- **Ноль зависимостей** — чистый Python 3.9+, ничего ставить не надо.

## Запуск

**Windows / вручную:**

```bash
python3 test_app.py     # самопроверка (33 проверки)
python3 main.py         # открывает окно приложения в браузере
```

**macOS:** двойной клик по `Запуск GhostReply.command`.

Открывается интерфейс `http://127.0.0.1:8787`:

- **«🔗 Мессенджеры»** — вставь ссылку и токен бота VK или Telegram,
  нажми «Подключить» — бот начнёт переписываться в этом мессенджере за тебя;
  ниже — живая лента событий (входящие/отправленные).
- слева — чаты (создай id нажатием «＋»),
- «📥 Импорт истории» — вставь переписку строками `Я: ...` / `Собеседник: ...`,
- блок «🧬 Твой стиль» показывает, как бот тебя разобрал,
- поле снизу — входящее сообщение, кнопка «Ответить» генерирует ответ,
- «⚙️ Настройки» — LLM-ключ, режим автоответ/черновик
  (сохраняются сразу, без перезапуска).

### Подключение VK

1. Настройки сообщества → «Сообщения» → включить «Сообщения от сообщества».
2. Там же → «Управление» (или API-функции) → создать ключ доступа с правом **messages**.
3. Вставить токен в «🔗 Мессенджеры» → «Подключить». Ссылку на сообщество/чат
   можно указать рядом — сохранится для справки, id сообщества достанется из неё.

### Подключения Telegram

1. @BotFather → `/newbot` → скопировать токен.
2. Вставить в «🔗 Мессенджеры» → «Подключить».
3. Написать боту или добавить его в группу — он ответит за тебя
   (в черновике-режиме ответ уйдёт тебе в «Избранное»).

С LLM (ключ можно вставить и в «⚙️ Настройки» внутри приложения):

```bash
export GHOST_LLM_API_KEY="sk-..."
export GHOST_LLM_MODEL="gpt-4o-mini"       # или groq/llama, ollama и т.п.
python3 main.py
```

Без ключа работает локальный фолбэк: распознаёт намерение
(приветствие, «когда?», «спасибо», вопросы, планы) и отвечает
шаблоном в твоём стиле (эмодзи, капс, восклицания).

Конфиг можно держать в `config.json` (см. `config.example.json`) и передавать
`--config config.json` — переменные окружения имеют приоритет.
Токены мессенджеров удобнее задавать в интерфейсе, но можно и через env:
`GHOST_TELEGRAM_TOKEN`, `GHOST_TELEGRAM_ALLOWED_CHATS` (id через запятую).

## HTTP API

| Метод | Путь | Тело | Что делает |
|---|---|---|---|
| GET | `/` | — | веб-интерфейс приложения |
| GET | `/chats` | — | список чатов со счётчиками |
| GET/DELETE | `/chat/<id>` | — | история чата / её удаление |
| GET | `/style/<id>` | — | профиль твоего стиля |
| GET/POST | `/settings` | поля настроек | показать / применить+сохранить |
| GET | `/connections` | — | статусы VK/Telegram |
| GET | `/events` | — | статусы + живая лента событий |
| POST | `/connect` | `{"messenger":"vk"\|"telegram","token","link?"}` | проверка токена и запуск бота |
| POST | `/disconnect` | `{"messenger":"vk"\|"telegram"}` | остановить и забыть токен |
| POST | `/history` | `{"chat_id", "messages":[{"sender":"me"\|"peer","text"}]}` | импорт истории чата |
| POST | `/message` | `{"chat_id", "text", "sender":"peer"}` | входящее → `{"reply","mode"}` |
| POST | `/reply` | `{"chat_id?", "text"}` | просто сгенерировать ответ |
| GET | `/health` | — | `{ok:true}` |

### Пример: подключить свой мессенджер

```bash
# 1. Залей историю переписки (ты — "me", собеседник — "peer")
curl -X POST localhost:8787/history -H 'Content-Type: application/json' -d '{
  "chat_id": "ivan",
  "messages": [
    {"sender": "peer", "text": "привет, ты где?"},
    {"sender": "me",   "text": "ку, на работе 😅"},
    {"sender": "peer", "text": "когда освободишься?"}
  ]
}'

# 2. Получи ответ, когда придёт новое сообщение
curl -X POST localhost:8787/message -H 'Content-Type: application/json' \
  -d '{"chat_id": "ivan", "text": "когда освободишься?"}'
# -> {"reply": "после шести норм, мигом 😅", "mode": "auto"}
```

В режиме `auto` ответ пишется в историю как твой; в `draft` — возвращается
черновик, и решать отправлять ли тебе.

## Как это работает

```
история чата ──► StyleProfile (твой стиль) ─┐
                                            ├─► промпт ─► LLM ─► доводка под стиль ─► ответ
последнее сообщение ────────────────────────┘                    │
                                                    нет LLM ─────┘ локальный фолбэк
```

Файлы:

- `ghostreply/static/index.html` — интерфейс (чаты, стиль, подключения, лента)
- `ghostreply/style.py` — разбор твоего стиля из истории
- `ghostreply/engine.py` — промпт, LLM-вызов, стилевая доводка, фолбэк по намерениям
- `ghostreply/history.py` — JSONL-хранилище чатов (`data/history/`)
- `ghostreply/api.py` — HTTP API + раздача интерфейса
- `ghostreply/telegram.py` — Telegram-адаптер (typing-паузы, черновик → «Избранное»)
- `ghostreply/vk.py` — VK-адаптер (Bots Long Poll, typing-паузы)
- `ghostreply/status.py` — статусы подключений и лента событий

## Данные

Вся история лежит локально в `data/history/*.jsonl` (в `.gitignore`).
Ничего наружу не уходит, кроме промптов к выбранному тобой LLM-провайдеру.
